## Findings

2. **glm-5-2 is the second model ever to pass ui-build.** A-d9b79b46: astra (W36, low/medium/high) was the only passer in any published matrix. The glm family's frontend strength is now confirmed on an independent lane, with the family's 5.2 generation.
3. **Review face is model-specific, not family-specific.** A-cdc3d11a: swe-medium ✓ 1.0 (first published pass anywhere) vs glm ✗ -4. A-47eea242: glm ✓ 3 vs swe-medium ✗ 1. Two review cases, two opposite splits — single-model claims about "review capability" are noise until replicated.
4. **glm-5-2's delivery-contract failure is a model defect, not infrastructure.** Six papers (ops ×2, req-drift ×4) ended with full analyses in chat and **no deliverable file written**; two same-day makeup replays reproduced the exact mode. Classified as delivery failure (真答不出), not `invalid_infrastructure`; marked ∅ with this footnote. A model that cannot honor "write report.md at path X" cannot be operated unattended regardless of its reasoning.
5. **The multi-dispatch crack replicates.** A-569dbe0d: glm 3/10. Every other published model maxes it at 10/10; glm-5.2's known weakness on fan-out dispatch work (previously observed looping on another lane) shows up here as fast, shallow failure. Structural, not quota.
6. **Vision stays a swe-medium scalp this week.** A-ea80d793 ✓ 3.0 — W37's only pass (luna/sol failed all five published bands; astra-medium passed it W36). Single run, replication queued.
7. **No token telemetry on this lane.** The provider reports zero usage counters through ACP. Wall clock is the only speed proxy: medium 3.0 h, glm 2.3 h cumulative for 26 papers.
